# Authoring Workflows

Now that you've seen how Transist works in the [Quickstart guide](../getting-started/quickstart.md), these guides help workflow authors build repeatable, inspectable workflows with clearer operational boundaries.

## Your Learning Path

We recommend reading these in order to build your skills progressively.

1. **[Build a Real Workflow](advanced-workflow-authoring.md)**
    Build and run a complete standalone workflow using the bundled `shell` plugin: typed input, a direct JSON output handoff, a manual gate, and a final echo.

2. **[Explore Common Patterns](workflow-patterns-cookbook.md)**
    Learn the standard building blocks of Transist automation, including conditional steps (`if`), loops (`loop`), and how to break large workflows into smaller, reusable subflows.

3. **[Get Help from AI](ai-assisted-authoring-with-repo-skills.md)**
    Discover how to use an AI agent that understands your local project. It can help you write, debug, and understand workflows faster.

## Build a Plugin

When you need your own action, follow
[Write Your First Plugin](../plugins/write-your-first-plugin.md) to build a
local Python APP greeting plugin and invoke it from a workflow.
