# Getting Started with Transist

Use these guides to evaluate a local Transist installation, understand the core concepts, and run your first inspectable workflow. They are not the production delivery path.

If you are new to Transist, start with the **Quickstart**. It is a short, hands-on path that installs the basics, runs one workflow, and inspects the resulting evidence.

## The Essentials

1. [**Quickstart**](quickstart.md)
    The fastest temporary standalone evaluation. You'll run a minimal workflow and inspect the resulting run record.

2. [**Installation and Local Setup**](installation-and-local-setup.md)
    A detailed guide to installing the `transist` CLI and preparing your local environment. If you hit any snags during the Quickstart, the answer is likely in here.

For a regular controlled runtime, begin with [Runtime Modes](../../reference/runtime-modes.md), then follow [Governed Runtime Setup and Delivery](../trust/governed-runtime-setup-and-delivery.md). Governed is the default `transist home init` posture.

### Where to Go Next

Once the first run is working, move to workflows that look more like your team's real work.

- [**Build Your First Real Workflow**](../authoring/advanced-workflow-authoring.md): Move from the minimal example to a multi-step workflow with real logic.
- [**Explore the Demos**](../../../../workflows/demos/getting_started/README.md): Check out a collection of ready-to-run examples that showcase different Transist features in action.
