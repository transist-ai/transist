# Transist 0.1.4

This public beta patch makes nested runs and human reviews easier to inspect in
`transist-server`. The runtime remains pre-1.0; support and stability limits are
unchanged.

## Nested Run Inspection

- The root run shows an execution outline and gate decisions from nested runs.
  Steps that launch child runs link to their active review and output tabs.
- The run that owns the gate previews the exact document revisions submitted
  for review. The UI remains read-only; the suggested CLI commands use the root
  run ID, as in the CLI TUI.
- Tab links stay at the tab bar and preserve the selected iteration. Output
  views default to the current execution, even when its artifact list is empty.
  Select an earlier iteration explicitly to inspect retained artifacts.
- Update `url` to 2.5.9 and `form_urlencoded` to 1.2.3 for RUSTSEC-2026-0592.

## Compatibility and Adoption

Runtime, admin, and server versions are `0.1.4`. Bundled workflows, modules,
plugins, and exact catalog pins remain `0.1.0`; schema and protocol identifiers
remain `v1`. The inspection changes do not alter workflow execution, rewrite
run history, or reconstruct outputs that were never captured.

Use the matching binaries from the signed release archive. See
[Compatibility and Stability](../reference/compatibility-and-stability.md),
[release artifact verification](../reference/release-artifact-verification.md),
and the [0.1.3 release notes](0.1.3.md) for previous changes.
