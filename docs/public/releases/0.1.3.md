# Transist 0.1.3

This public beta patch updates JSON Schema validation and strengthens plugin
schema path handling. The runtime remains pre-1.0; existing support and stability
limits are unchanged.

## Schema Validation and Path Safety

- Upgrade Rust JSON Schema validation to `jsonschema` 0.61.2. Installed workflow
  receipts from the previous validator revision are revalidated without rewriting
  the install index during checks.
- Reject percent-encoded parent-directory segments in plugin schema paths and
  references. Use package-relative paths without parent traversal instead.
- Refresh dependencies and third-party notices.

Runtime, admin, and server versions are `0.1.3`. Bundled workflows, modules,
plugins, and exact catalog pins remain `0.1.0`; schema and protocol identifiers
remain `v1`.

See the [0.1.2 release notes](0.1.2.md) for evidence and handshake fixes, the
[0.1.1 release notes](0.1.1.md) for loop-routing adoption and recovery, and
[Compatibility and Stability](../reference/compatibility-and-stability.md).
