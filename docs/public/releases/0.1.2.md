# Transist 0.1.2

This public beta patch corrects runtime evidence and process handshake
diagnostics. The runtime remains pre-1.0; existing support and stability limits
are unchanged.

## Runtime Evidence

- External-transfer evidence SHA-256 references now match the exact JSON bytes
  persisted by the artifact store. Historical records are not rewritten.
- Adapter invocation start and finish timestamps now capture actual wall-clock
  times independently of monotonic elapsed duration, including failure and
  cancellation results. Existing invocation records retain their timestamps.

## Process Handshake Diagnostics

- Process stdout closure before the APP handshake response is reported as a
  transport failure in live preflight and invocation diagnostics. Stdout read
  errors are also transport failures; handshake deadline expiry remains a timeout.
- Malformed handshake JSON or an invalid handshake remains a protocol error. See
  [Process Handshake Failures](../reference/app.md#process-handshake-failures).

Runtime, admin, and server versions are `0.1.2`. Bundled workflows, modules,
plugins, and exact catalog pins remain `0.1.0`; schema and protocol identifiers
remain `v1`.

See the [0.1.1 release notes](0.1.1.md) for loop-routing adoption and recovery,
the [initial release](0.1.0.md) for baseline capabilities, and
[Compatibility and Stability](../reference/compatibility-and-stability.md).
