# Support

Repository visibility does not imply unlimited public support, free consulting,
or an open-ended community support commitment.

## Support Paths

- Use the repository issue tracker for reproducible defects, documentation
  corrections, and focused implementation proposals.
- For general inquiries, contact <hello@transist.ai>.
- Implementation and support agreements are available separately.

## Scope Boundaries

- Reproducible bugs are in scope.
- Documentation corrections are in scope.
- Focused product and kernel proposals are in scope when aligned with
  `VISION.md` and `AGENTS.md`.
- Bespoke architecture design, free implementation work, and open-ended
  consulting are out of scope unless covered by a separate agreement.

## Security

Do not report security vulnerabilities in a normal issue. Follow
[`SECURITY.md`](SECURITY.md) or email <security@transist.ai>.
